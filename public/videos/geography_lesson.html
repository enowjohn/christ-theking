🌍 Geography Field Study

Geography Lesson for GCE O/L Students

Teacher: Dr. Lisa Chen | Duration: 44:30

Lesson Objectives

  • Understand field study methods
  • Learn map reading skills
  • Master data collection
  • Analyze geographical features

Field Study Equipment

• Maps and compass

• Measuring tape

• Notebook and pencil

• Camera for documentation

Map Reading

Scale - Distance ratio

Legend - Map symbols

Contour lines - Elevation

Grid references - Location

Data Collection

1. Observe and record

2. Take measurements

3. Sketch features

4. Note patterns

Analysis Methods

• Compare with maps

• Identify patterns

• Draw conclusions

• Present findings
