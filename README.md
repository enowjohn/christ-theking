# Christ the King School Website

A professional, modern website for Christ the King School built with HTML, CSS, and JavaScript.

## Features

### 🏠 Home Page
- Hero banner with school name and logo
- Auto-scrolling announcements ticker
- Quick access cards to all major features
- School statistics and achievements
- Interactive quiz and statistics modals
- Responsive design with animations

### 📚 Academics Page
- Download past questions for all subjects (15+ subjects)
- Subject-wise question banks (2021, 2022, 2023)
- Student marks entry system for teachers
- Downloadable marks reports
- Academic performance statistics
- Industrial and general education subjects

### 📖 Study & Teaching Page
- Comprehensive study materials for all subjects
- Teaching resources and lesson plans
- Interactive subject-specific quizzes
- Subject guides with study strategies
- Downloadable materials and resources
- Study tips and learning strategies

### 📚 Library & Videos Page
- Digital library with searchable e-books
- Category filtering (Academic, Fiction, Reference, Industrial)
- Video lessons with subject categorization
- Featured resource bundles
- Reading progress tracking
- Video player simulation

## Technology Stack

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with animations and gradients
- **JavaScript (ES6+)** - Interactive features and functionality
- **Local Storage** - Progress tracking and data persistence
- **Responsive Design** - Mobile-first approach
